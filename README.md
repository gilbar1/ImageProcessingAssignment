# Image Processing Assignment

Built on [BasicOpenGL](https://github.com/OfirGiladBGU/BasicOpenGL).

On Windows, run `build-assignment.bat` from the repository root with Visual Studio C++ Build Tools, Windows tar, and an OpenGL 4.3 driver. The script unpacks the bundled build dependencies on first run. It writes four PNG images and four comma-separated TXT files into the repository root.

See `ASSIGNMENT.txt` for the algorithms and implementation notes.
